About

Mentalitys | Custom Enchantments is a Minecraft 1.20.1 (Fabric API) mod that adds 19 unique enchantments with flexible configuration via Cloth Config API. Each enchantment can be toggled individually, and all parameters — levels, chances, durations, radii — are tweakable via the GUI settings screen (Mod Menu) without restarting the server. Config file: config/custom-enchants.json. Mentalitys | Custom Enchantments — мод для Minecraft 1.20.1 (Fabric API), добавляющий 19 уникальных зачарований с гибкой настройкой через Cloth Config API. Все зачарования можно включать и выключать по отдельности в конфиг-файле config/custom-enchants.json, а параметры настраиваются через GUI (Mod Menu).

src/main/ — server-side enchantment logic and config. src/client/ — client-side effects and GUI. src/main/ — серверная логика зачарований и конфиг. src/client/ — клиентские эффекты и GUI.
