# Mentalitys | Custom Enchantments

> [Русская версия](README_RU.md)

Custom Fabric enchantments for Minecraft.

## Current release

**3.2.5** for Minecraft **1.21.1** and **1.21.11**.

Minecraft **1.20.1** remains on **3.2.4** because the Double Jump hotfix is not needed there.

Loader: **Fabric**.

## Branches

`main` contains project information only. The actual mod source is maintained
in the version-specific branches above. Choose the release asset or source
branch that matches your Minecraft version; one JAR does not support every
version.
