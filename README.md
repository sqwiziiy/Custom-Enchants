## Branches

`main` contains the current Minecraft 1.21.11 source. Other supported Minecraft versions use dedicated maintenance branches. Choose the JAR for your Minecraft version; one JAR does not support every version.

See [the branch map](docs/BRANCHES.md) for the repository layout and archived maintenance lines.
