# Список изменений

> [English version](CHANGELOG_EN.md)

Все заметные изменения мода **Mentalitys | Custom Enchantments** документируются здесь.

## [1.1.0] - 2026-03-25

### Добавлено

- **Двойной прыжок (Double Jump)** — новое зачарование для ботинок (очень редкое, макс. уровень 1). Позволяет совершить второй прыжок в воздухе.
- Торговля у жителя-Библиотекаря: Двойной прыжок I — Эксперт (тир 4), 38 изумрудов.
- **Cloth Config API** — конфигурация мода через JSON-файл (`config/custom-enchants.json`) и GUI-экран настроек.
- Настраиваемая длительность эффекта Сияющего удара для каждого уровня.
- Возможность включать/выключать каждое зачарование по отдельности.
- Локализация интерфейса настроек (EN/RU).
- Английская версия README и CHANGELOG.

### Изменено

- Мод переименован с «Glow Strike» на **«Mentalitys | Custom Enchantments»**.
- ID мода изменён с `glowstrike` на `custom-enchants`.
- Код рефакторен: разделение на пакеты `config` и `enchantment`.
- Длительность Сияющего удара теперь читается из конфига.

---

## [1.0.0] - 2026-03-25

### Добавлено

- **Сияющий удар (Glow Strike)** — зачарование для мечей и топоров (макс. уровень 3).
- Эффект **Свечение**: 2 сек (I), 4 сек (II), 7 сек (III).
- Несовместимость с **Отбрасыванием** (Knockback).
- Эффект срабатывает только при атаке игроком живого существа.
- Торговля у жителей-Библиотекарей (тиры 1, 3, 5).
- Локализация: English (`en_us.json`) и Русский (`ru_ru.json`).
- Сборка для Minecraft 1.20.1, Fabric API, Java 21.
