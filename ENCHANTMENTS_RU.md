# Зачарования

Актуальная справка для Minecraft 1.20.1. Римские цифры — поддерживаемые
уровни; все IDs зарегистрированы в пространстве имён `custom-enchants`.

| Зачарование | Предметы | Макс. | Текущее поведение |
|---|---|---:|---|
| Сияющий удар (Glow Strike) | меч, топор, трезубец | III | Удар игрока накладывает Свечение; длительность настраивается. Несовместимо с Knockback, а на трезубце также с Shadow Blade. |
| Двойной прыжок (Double Jump) | ботинки | I | Даёт один прыжок в воздухе, частицы и обработку прочности. |
| Бур (Drill) | кирка, лопата | I | Ломает безопасную плоскость 3×3; при приседании остаётся один блок. |
| Ядовитый клинок (Poison Blade) | меч, топор | III | Удар игрока накладывает Отравление; длительность настраивается. Несовместимо с Fire Aspect. |
| Лесоруб (Lumberjack) | топор | III | Безопасно рубит обнаруженное натуральное дерево в пределах лимита блоков. |
| Теневой клинок (Shadow Blade) | трезубец | III | Шанс телепорта за цель и Замедление; шанс и длительность настраиваются. |
| Магнит (Magnet) | совместимый инструмент/оружие | I | Притягивает ближайшие предметы в радиусе конфигурации. |
| Автоплавка (Auto Smelt) | кирка, лопата, топор | I | Использует обычный loot pipeline и не обходит callbacks ломания. Несовместимо с Fortune. |
| Растительность (Vegetation) | мотыга | III | Даёт дополнительные растительные дропы с настраиваемым шансом. |
| Отскок (Rebound) | щит | III | При блокировании возвращает подходящие атаки с силой отбрасывания по уровню. |
| Эхо-удар (Feedback) | щит | I | При блокировании защищает от предусмотренных вредных/магических путей урона, очищает эффекты и может лечить/чинить. |
| Второе дыхание (Second Wind) | поножи | I | Даёт короткое ускорение с кулдауном после триггера. |
| Милость хранителя (Guardian's Grace) | нагрудник | III | Защитный эффект с настраиваемым шансом. |
| Уязвимость (Vulnerability) | лук, арбалет | III | Шанс игнорирования/смягчения урона; процент настраивается. |
| Крепкая нить (Tether Master) | удочка | III | Увеличивает силу притяжения при подсекании сущностей. |
| Ярость Неба (Sky Rage) | лук, арбалет | III | Во время грозы и при открытом небе стрела может вызвать молнию; кулдаун настраивается. |
| Собиратель искр (XP Syphon) | меч | III | Удар может создать сферы опыта до смерти цели. |
| Кинетический разряд (Kinetic Discharge) | элитры | III | Быстрое приземление создаёт волну отбрасывания; III уровень также наносит настроенный урон. |
| Скалковое цветение (Sculk Bloom) | меч | II | Убийство может запустить распространение скалка вокруг места смерти. |

Книги, наковальня, creative и команды используют поддерживаемые vanilla-пути.
Для некоторых зачарований область предметов расширена специально для книг или
наковальни. Полное покрытие multiplayer, protection, loot, trade и anvil
остаётся задачей автоматизированной/in-world фазы; локальная матрица —
`docs/TEST_MATRIX.md`.
