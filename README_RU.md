# Mentalitys | Custom Enchantments

> [English version](README.md)

Мод для **Minecraft 1.20.1** на **Fabric API**, добавляющий уникальные зачарования с гибкой настройкой через **Cloth Config API**.

---

## Зачарования

### ⚔️ Сияющий удар (Glow Strike)

Зачарование для **мечей, топоров и тризубцев**. При ударе накладывает эффект **Свечение** на цель, делая её видимой сквозь стены.

| Уровень | Длительность | Тики |
|---------|-------------|------|
| I       | 2 сек       | 40   |
| II      | 4 сек       | 80   |
| III     | 7 сек       | 140  |

- **Редкость:** Редкое
- **Макс. уровень:** 3
- **Несовместимо** с Отбрасыванием (Knockback)
- Эффект срабатывает только если атакующий — игрок, а цель — живое существо
- Длительность каждого уровня настраивается через конфиг

### 🦘 Двойной прыжок (Double Jump)

Зачарование для **ботинок**. Позволяет совершить **второй прыжок в воздухе**.

| Уровень | Эффект         |
|---------|----------------|
| I       | Двойной прыжок |

- **Редкость:** Очень редкое
- **Макс. уровень:** 1
- При прыжке появляются **белые частицы** под ногами
- **67% шанс** потратить 1 прочность ботинок (зачарование **Прочность/Unbreaking** снижает шанс)
- Работает только если игрок не в воде и не в лаве
- Можно включить/выключить через конфиг

### ⛏️ Бур (Drill)

Зачарование для **кирки и лопаты**. Ломает блоки в области **3×3** вокруг центрального блока.

| Уровень | Эффект           |
|---------|------------------|
| I       | Копание 3×3      |

- **Редкость:** Очень редкое
- **Макс. уровень:** 1
- **Не работает при зажатом Shift** (приседание) — позволяет копать по 1 блоку
- Плоскость 3×3 определяется по стороне блока, по которой игрок копает
- Расходует 1 прочность за каждый доп. блок (Unbreaking работает)
- Ломает только блоки, подходящие для инструмента; неразрушимые (бедрок и т.д.) пропускаются
- Можно включить/выключить через конфиг

### 🗡️ Ядовитый клинок (Poison Blade)

Зачарование для **мечей и топоров**. При ударе накладывает эффект **Отравление** на цель.

| Уровень | Длительность |
|---------|--------------|
| I       | 2 сек        |
| II      | 3 сек        |
| III     | 4 сек        |

- **Редкость:** Редкое
- **Макс. уровень:** 3
- **Несовместимо** с Заговором огня (Fire Aspect)
- Эффект срабатывает только если атакующий — игрок, а цель — живое существо
- Длительность каждого уровня настраивается через конфиг
- Можно получить на столе зачарований и через торговлю с жителями

### 🪵 Лесоруб (Lumberjack)

Зачарование для **топоров**. Срубает всё **дерево** при ломке одного блока древесины. Умное обнаружение гарантирует, что ломаются только натуральные деревья, а не постройки игроков.

| Уровень | Размер деревьев   | Макс. блоков |
|---------|---------------------|---------------|
| I       | Маленькие деревья  | 16            |
| II      | Средние деревья   | 48            |
| III     | Большие деревья   | 128           |

- **Редкость:** Редкое
- **Макс. уровень:** 3
- Ломает только **брёвна** того же типа (дуб, берёза, ель, багровый, искажённый и т.д.)
- Работает с **незер-деревьями** (багровые и искажённые стволы)
- Проверяет, что блок — часть натурального дерева (ищет листву или блоки нароста на вершине)
- **Не ломает** блоки ниже сломанного (безопасно для стен из брёвен)
- Расходует 1 прочность за каждое бревно (Unbreaking работает)
- Можно вкл/выкл через конфиг; макс. блоков настраивается для каждого уровня

### 🗡️ Теневой клинок (Shadow Blade)

Зачарование для **тризубца**. При ударе с определённым шансом **телепортирует игрока за спину цели** и накладывает **Замедление II** на цель.

| Уровень | Шанс | Длительность замедления |
|---------|------|-------------------------|
| I       | 15%  | 1 сек                   |
| II      | 25%  | 2 сек                   |
| III     | 35%  | 3 сек                   |

- **Редкость:** Очень редкое
- **Макс. уровень:** 3
- **Несовместимо** с Громоверзцем (Channeling) и Тягуном (Riptide)
- Телепортирует игрока на 1.5 блока за спину цели, лицом к ней
- **Бонус расстояния:** до +10% шанса при броске на 30 блоков (линейное масштабирование)
- Шанс и длительность замедления настраиваются для каждого уровня
- Можно получить на столе зачарований и через торговлю с жителями

### 🧲 Магнит (Magnet)

Зачарование для **кирки, топора, лопаты и мотыги**. При добыче блоков предметы в настраиваемом радиусе **автоматически попадают в инвентарь** игрока.

| Уровень | Эффект                            |
|---------|-----------------------------------|
| I       | Авто-сбор в радиусе 5 блоков      |

- **Редкость:** Редкое
- **Макс. уровень:** 1
- Работает с Буром и Лесорубом — собирает все предметы от дополнительных блоков
- Радиус сбора настраивается в конфиге (по умолчанию 5 блоков)
- Можно получить на столе зачарований и через торговлю с жителями
- Можно включить/выключить через конфиг

### 🔥 Автопечка (Auto Smelt)

Зачарование для **кирки**. При добыче руд, требующих переплавки, **автоматически выдаёт переплавленный результат** вместо сырой руды.

| Уровень | Эффект                                      |
|---------|--------------------------------------------|
| I       | Переплавка железной, золотой, медной руды |

- **Редкость:** Редкое
- **Макс. уровень:** 1
- Применяется только к рудам с рецептом переплавки (железная, золотая, медная руды и их глубинносланцевые варианты)
- Даёт опыт за переплавку
- Можно получить на столе зачарований и через торговлю с жителями
- Можно включить/выключить через конфиг

### 🌱 Вегетация (Vegetation)

Зачарование для **мотыги**. При разрушении **взрослого растения** шанс **автоматической посадки**.

| Уровень | Шанс |
|---------|------|
| I       | 30%  |
| II      | 60%  |
| III     | 100% |

- **Редкость:** Редкое
- **Макс. уровень:** 3
- Работает с пшеницей, морковью, картофелем, свёклой, адским наростом
- Посадка происходит на следующем серверном тике после сбора
- Только что посаженное растение защищено от случайного слома в течение 0.5 сек
- Шанс для каждого уровня настраивается
- Можно получить на столе зачарований и через торговлю с жителями
- Можно включить/выключить через конфиг

### 🛡️ Эластичность (Rebound)

Зачарование для **щита**. При блокировании удара моба **отбрасывает атакующего назад**, при этом сам игрок тоже получает небольшой **импульс назад**.

| Уровень | Сила отдачи |
|---------|-----------------|
| I       | 0.5             |
| II      | 1.0             |
| III     | 2.0             |

- **Редкость:** Редкое
- **Макс. уровень:** 3
- **Не** наносит урона
- Тратит дополнительную прочность щита (1 за уровень)
- Игрок также получает небольшой само-отброс (30% от отдачи атакующего)
- Сила отдачи настраивается для каждого уровня
- Можно получить на столе зачарований и через торговлю с жителями
- Можно включить/выключить через конфиг

### 🛡️ Эхо-удар (Feedback)

Зачарование для **щита**. При блокировании **магической атаки** (зелье ведьмы, челюсти эвокера, снаряд шалкера) щит **восстанавливает 2 прочности** и игрок получает **1 сердце** здоровья. Также **блокирует все негативные эффекты зелий** (яд, замедление, слабость и т.д.) пока щит поднят.

| Уровень | Эффект                                                |
|---------|-------------------------------------------------|
| I       | +2 прочности, +1 сердце при блоке магии |

- **Редкость:** Редкое
- **Макс. уровень:** 1
- Срабатывает на магический урон, непрямую магию и снаряды шалкера
- Блокирует негативные эффекты зелий пока щит поднят
- Количество лечения и восстановления прочности настраиваются
- Можно получить на столе зачарований и через торговлю с жителями
- Можно включить/выключить через конфиг

## Настройка (Cloth Config)

Мод поддерживает конфигурацию через **Cloth Config API**. Файл конфига: `config/custom-enchants.json`.

### Параметры

| Параметр                 | По умолчанию | Описание                              |
|--------------------------|-------------|---------------------------------------|
| `glowStrikeEnabled`      | `true`      | Включить/выключить Сияющий удар       |
| `glowStrikeDurationL1`   | `40`        | Длительность I уровня (тики)          |
| `glowStrikeDurationL2`   | `80`        | Длительность II уровня (тики)         |
| `glowStrikeDurationL3`   | `140`       | Длительность III уровня (тики)        |
| `doubleJumpEnabled`      | `true`      | Включить/выключить Двойной прыжок     |
| `drillEnabled`           | `true`      | Включить/выключить Бур                |
| `poisonBladeEnabled`     | `true`      | Включить/выключить Ядовитый клинок    |
| `poisonBladeDurationL1`  | `40`        | Длительность I уровня (тики)          |
| `poisonBladeDurationL2`  | `60`        | Длительность II уровня (тики)         |
| `poisonBladeDurationL3`  | `80`        | Длительность III уровня (тики)        |
| `lumberjackEnabled`      | `true`      | Включить/выключить Лесоруб            |
| `lumberjackMaxBlocksL1`  | `16`        | Макс. блоков I уровень                |
| `lumberjackMaxBlocksL2`  | `48`        | Макс. блоков II уровень               |
| `lumberjackMaxBlocksL3`  | `128`       | Макс. блоков III уровень              |
| `shadowBladeEnabled`     | `true`      | Включить/выключить Теневой клинок     |
| `shadowBladeChanceL1`    | `15`        | Шанс I уровня (%)                    |
| `shadowBladeChanceL2`    | `25`        | Шанс II уровня (%)                   |
| `shadowBladeChanceL3`    | `35`        | Шанс III уровня (%)                  |
| `shadowBladeSlowDurationL1` | `20`    | Длительность замедления I уровня (тики) |
| `shadowBladeSlowDurationL2` | `40`    | Длительность замедления II уровня (тики) |
| `shadowBladeSlowDurationL3` | `60`    | Длительность замедления III уровня (тики) |
| `magnetEnabled`          | `true`      | Включить/выключить Магнит             |
| `magnetRadius`           | `5`         | Радиус сбора (блоки)                  |
| `autoSmeltEnabled`       | `true`      | Включить/выключить Автопечку           |
| `vegetationEnabled`      | `true`      | Включить/выключить Вегетацию          |
| `vegetationChanceL1`     | `30`        | Шанс I уровня (%)                  |
| `vegetationChanceL2`     | `60`        | Шанс II уровня (%)                 |
| `vegetationChanceL3`     | `100`       | Шанс III уровня (%)                  |
| `reboundEnabled`         | `true`      | Включить/выключить Эластичность        |
| `reboundKnockbackL1`    | `5`         | Отдача I уровня (×0.1)            |
| `reboundKnockbackL2`    | `10`        | Отдача II уровня (×0.1)           |
| `reboundKnockbackL3`    | `20`        | Отдача III уровня (×0.1)          |
| `feedbackEnabled`        | `true`      | Включить/выключить Эхо-удар       |
| `feedbackHealAmount`     | `2.0`       | Количество лечения (HP)              |
| `feedbackRepairAmount`   | `2`         | Восстановление прочности               |

## Требования

- Minecraft 1.20.1
- Fabric Loader ≥ 0.18.4
- Fabric API
- Cloth Config API ≥ 11.0.0
- Java 21+

## Сборка

```bash
./gradlew build
```

Скомпилированный jar будет в `build/libs/`.
