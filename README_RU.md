Мод для Minecraft 1.20.1 на Fabric с 19 настраиваемыми зачарованиями.
Игровая логика принадлежит серверу; Cloth Config и Mod Menu дают интерфейс
настройки на клиенте, если эти моды установлены.

## Совместимость

- Minecraft `~1.20.1`
- Java `>=17`
- Fabric Loader `>=0.18.4`
- Fabric API `>=0.92.7+1.20.1`
- Cloth Config `>=11.1.118`
- Mod Menu `>=7.2.2` (необязательно)

Полный список из 19 зачарований, предметы, уровни, конфликты, сделки
библиотекарей, поля конфигурации и ограничения приведены в справочниках.

## Установка

Скачайте `custom-enchants-3.1.1.jar` из [релиза 3.1.1](https://github.com/sqwiziiy/Custom-Enchants/releases/tag/v3.1.1) и поместите его в каталог `mods/` Fabric. Нужны Fabric Loader `>=0.18.4`, Fabric API `>=0.92.7+1.20.1`, Cloth Config `>=11.1.118` и Java `>=17`; Mod Menu `>=7.2.2` необязателен.

## Известное ограничение

В Minecraft 1.20.1 Магнит + Лесоруб обычно собирает связанные дропы, но на сложных настоящих деревьях часть вторичных брёвен может остаться рядом на земле. Контракт релиза сохраняет все дропы: потеря или дублирование предметов недопустимы.
