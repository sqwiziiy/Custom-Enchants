# Mentalitys | Custom Enchantments

> [English version](README.md)

[![CI](https://github.com/sqwiziiy/Custom-Enchants/actions/workflows/ci.yml/badge.svg?branch=3.0)](https://github.com/sqwiziiy/Custom-Enchants/actions/workflows/ci.yml)

Мод для Minecraft 1.20.1 на Fabric с 19 настраиваемыми зачарованиями.
Игровая логика принадлежит серверу; Cloth Config и Mod Menu дают интерфейс
настройки на клиенте, если эти моды установлены.

## Содержание

- [Справочник зачарований](ENCHANTMENTS_RU.md)
- [Справочник конфигурации](CONFIGURATION_RU.md)
- [История изменений](CHANGELOG.md)
- [Репозиторий исходников](https://github.com/sqwiziiy/Custom-Enchants)
- [Ошибки и предложения](https://github.com/sqwiziiy/Custom-Enchants/issues)

## Совместимость

- Minecraft `~1.20.1`
- Java `>=17`
- Fabric Loader `>=0.18.4`
- Fabric API `>=0.92.7+1.20.1`
- Cloth Config `>=11.1.118`
- Mod Menu `>=7.2.2` (необязательно)

Полный список из 19 зачарований, предметы, уровни, конфликты, сделки
библиотекарей, поля конфигурации и ограничения приведены в справочниках.
